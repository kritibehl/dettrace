# XCTestReplayValidation

Small XCTest-style validation examples for DetTrace replay outputs.

This is a lightweight proof artifact for Apple-style QA and validation workflows.

## What it validates

- expected replay output
- actual replay output
- first divergence index
- probable defect type
- root-cause field
- replay regression decision

## Safe claim

This demonstrates XCTest-style validation familiarity. It does not claim production Apple test ownership or an Xcode project shipped to users.
