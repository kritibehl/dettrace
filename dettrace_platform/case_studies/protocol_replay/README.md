# Protocol Replay Pack

Simulated replay scenarios for protocol and lifecycle debugging.

## Scenarios

- HTTP/TCP/DNS/TLS failure
- gRPC/RPC lifecycle timeout
- Go context cancellation / deadline exceeded
- systemd-style health check and connection-pool exhaustion

These are trace-driven debugging artifacts, not production network captures.

## Purpose

Demonstrate replay-based debugging for:
- HTTP
- TCP/IP
- DNS
- TLS
- RPC/gRPC lifecycle
- Go context cancellation
- service health checks
- connection-pool diagnostics
