# Astronomy Shop External Validation

DetTrace was validated against the OpenTelemetry Astronomy Shop at pinned upstream commit:

`8c47d47c9ac27710d2b2a153bcd53e483bffe66d`

The experiments use deterministic 40-request, single-worker captures and standard OTLP/Collector JSONL ingestion.

## Latency regression

A one-second international shipping delay preserved functional success while changing the distributed execution.

Observed DetTrace localization:

- `shipping`
- `POST /ship-order`
- p95: `24.00 ms -> 1015.23 ms`
- CI decision: `FAIL`

All workload endpoint requests remained successful.

## Topology regression

A controlled checkout candidate performs one redundant `GetCart` RPC before the functional `GetCart` RPC.

Canonical span-graph comparison preserves edge multiplicity and detects the matching `GetCart` edge changing from one occurrence to two.

The perturbation does not change the response used by checkout.

## Request-specific error regression

The payment failure feature flag is enabled at the Astronomy Shop `25%` variant while unrelated fault flags remain disabled.

The workload validity gate requires healthy endpoints to remain successful while checkout produces actual failures.

DetTrace evaluates OpenTelemetry error-rate changes independently from latency regression thresholds.
